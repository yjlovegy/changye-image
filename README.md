# 长夜的绘图器

SillyTavern 剧情配图扩展，基于 **柏柏** 的 [ST-BaiBai-Image](https://github.com/baibai-git/ST-BaiBai-Image) 修改，当前版本 **V1.3.3**（安装版本 `1.3.3`）。

本仓库由长夜维护增强版，并非原作者官方仓库。原有设置键与数据格式保留兼容，界面名称统一为“长夜的绘图器”；内部标识与历史图片目录沿用旧格式，以兼容已保存的数据。

## 安装

在酒馆打开 **扩展 → 安装扩展**，粘贴下面的地址：

```text
https://github.com/yjlovegy/changye-image
```

安装完成后刷新酒馆页面。进入插件的“工作流”，在“配置”中填写自己的 ComfyUI 地址并测试连接，再导入工作流、选择模型；仓库不附带模型、API 密钥或个人工作流。

**已有上游原版或 ZIP 修改版：请先停用旧版，再启用本版。不要同时启用两份，否则会重复处理消息和图片。** 建议先导出/备份旧版设置；本版沿用原设置命名空间，不主动清空配置。

## 更新

在酒馆扩展管理中点击本扩展的更新按钮，或在插件设置页检查更新，更新后刷新网页。版本检查与更新来源均指向本仓库。

通过 ZIP 复制的旧目录没有 Git 安装记录，需要先通过上面的链接安装本版，才能使用酒馆的 Git 更新功能。更新仓库代码不会替你下载新的模型，也不会自动更换你的工作流。

## 主要功能

- 根据剧情生成配图提示词，也可选中文字后手动配图。
- 人物固定外貌管理，支持脸型、五官和角色特征；画面动作、神态与位置关系随剧情描述。
- ComfyUI 工作流的模型、文本编码器、编码器类型、VAE、采样器、调度器、步数、CFG 和降噪参数可在插件中设置。
- 每个工作流独立保存固定正面前缀/后缀与固定负面提示词。
- LoRA 标签编辑与同步、共享 LoRA 收藏及备注。
- 自定义宽高、共享常用尺寸库、每个工作流独立默认尺寸；单张图片可选尺寸并重新生成。
- 工作流 JSON 上传、下载、粘贴及保存。
- 按修改意见调用副 API 生成新的正负提示词，确认后重新生图。
- 图库管理；可选 Windows 文件夹助手。

复杂姿态及人物一致性仍受底模、工作流、参考图和提示词影响，功能不保证每次出图完全一致。

## V1.3.1

- 工作流新增两个独立开关：“出图时使用负面词”和“AI 自动生成负面词”。关闭使用时保留所有文字，只在本次提交的标准负面 conditioning 入口置零；文生图、手动局部重绘和自动修复统一遵循。关闭 AI 生成时不再要求或接纳 AI 新编写的负面词，旧图负面与手填内容保留。
- 两个开关按工作流保存；旧配置默认启用，升级不会清空已保存内容。Krea2 Turbo 官方推荐不使用 CFG，而 RAW 可使用负面引导；插件不根据模型名称擅自切换用户设置。

- 新增“保存当前工作流”和“放弃修改”。LoRA、模型、采样、固定提示词、尺寸、自动修复与示例图关联使用临时草稿；各处“应用/同步”可用于试图，只有“保存当前工作流”覆盖已保存配置。统一保存也会收集尚未应用的控件输入；无效参数会拦截保存。
- 切换工作流、切换页面或关闭设置时，可保存、放弃或保留临时修改。临时修改只在本次页面会话有效，刷新后恢复已保存配置。共享 LoRA 收藏和尺寸库仍单独自动保存。

## V1.3.0

- 图片工具栏新增魔法棒“手动局部重绘”：自动载入当前图，支持画笔、橡皮擦、撤销、重做、缩放；涂选任意区域后描述修改要求。结果先对比，确认后保存为新版本，原图保留。
- “工作流 → 模型与采样”下方新增“出图后自动修复”，按工作流独立保存手部/脚部选项，默认关闭。SAM3 识别区域后用 LanPaint 重绘；未识别到则保留原图，修复失败也返回底图。
- Krea2 与 Anima 共用局部重绘处理，沿用所选工作流的模型、编码器、VAE、LoRA、步数、CFG 和采样配置。目前支持只有一个标准 KSampler、标准 CLIPTextEncode 与直接 VAE 解码的 API 工作流；复杂多采样工作流会明确提示，不猜测分支。
- 手动重绘支持停止；保存时再次核对聊天与楼层，避免切换聊天后写错位置。自动修复前后的版本分别保存，并记录使用的工作流及随机种子。

### 局部重绘依赖

在 ComfyUI 安装 [LanPaint](https://github.com/scraed/LanPaint) 和 [Inpaint Crop and Stitch](https://github.com/lquesada/ComfyUI-Inpaint-CropAndStitch)，重启 ComfyUI。保留已有 Krea2 / Anima 主模型、对应的 Qwen 编码器和 VAE，无需额外专用重绘底模。编码器类型需与模型匹配（Krea2 使用 krea2，Anima 使用 anima）。

自动修复还需要支持 SAM3_Detect 的 ComfyUI，以及 models/checkpoints 中的 SAM3 模型。本机验证使用 sam3.1_multiplex_fp16.safetensors。新电脑需要自行安装这些 ComfyUI 依赖；仅更新酒馆扩展不会下载模型。

浏览器需要能直连 ComfyUI 并上传原图/遮罩；跨端口访问需要开启 ComfyUI CORS。仅在可信本地网络使用对应访问设置。检测到手脚不代表判断它画错，重绘也不保证改善，请用历史版本比较。局部重绘的修改要求直接传给模型，建议使用简洁英文目标画面描述。

## 可选：“打开文件夹”助手

普通酒馆扩展安装不会安装服务器插件。**仅需要在 Windows 本机点击图库后弹出资源管理器的用户才需要本节。**

1. 将本仓库 `server-plugins/baibai-image-folders` 文件夹复制到 `SillyTavern/plugins/baibai-image-folders`。
2. 在酒馆 `config.yaml` 中设置 `enableServerPlugins: true`。
3. 关闭原酒馆启动窗口，用原来的启动方式重新启动。
4. 使用 `http://127.0.0.1:8000` 或自己的本机酒馆端口访问。点击图库分组的“打开文件夹”；手动删减后重新读取图库。

远程访问不支持打开服务器桌面窗口。服务助手只接受当前酒馆用户已有的长夜的绘图器图片目录；不支持任意磁盘路径。已有文件夹修正版助手的用户无需重复安装。

## 开发

源代码在 `src`，酒馆直接加载已提交的 `dist` 文件，使用者不需要编译。

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
```

发布新版时同时提交 `package.json`、`manifest.json` 和重新构建的 `dist`。服务助手如有更新，需要手动同步并重启酒馆。

本次发行通过 TypeScript 检查、生产构建和自动测试；不包含个人聊天、角色卡、图库、接口凭据或个人工作流。模型的真实出图需在自己的环境中验证。
